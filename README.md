# 레이나 · 마사지

PSD 레이어를 PixiJS WebGL 메쉬로 움직이는 캐릭터 마사지 페이지입니다. 앱 코드는 `index.html` 하나이며, 원본 PSD는 `assets/riana.psd`입니다(제공된 `Reina_1.psd`). 페이지는 먼저 `assets/layers/`의 레이어 이미지(1.0MB)를 읽고, 없으면 PSD를 읽습니다. 두 경로의 렌더링 결과는 픽셀 단위로 같습니다.

## 레이어 이미지 다시 만들기

PSD를 바꿨다면 저장소 루트에서 아래를 실행하세요. `assets/layers/`의 PNG와 `manifest.json`이 새로 만들어집니다.

```bash
npm install --no-save ag-psd
node tools/export-layers.cjs assets/riana.psd assets/layers
```

## 실행

HTTP 서버로 저장소 루트를 서비스하세요. 예: `python -m http.server 8080` 후 `http://localhost:8080` 접속. GitHub Pages에서도 실행할 수 있습니다. 파일을 직접 열면 브라우저의 로컬 fetch 제한 때문에 PSD 파일 선택이 필요합니다. PixiJS 7.4.3은 jsDelivr CDN에서 로드하므로 인터넷 연결이 필요합니다. ag-psd 27.0.0은 PSD를 읽을 때만 내려받습니다.

### 링크로 시작 상태 지정 (크랙 채팅 연동)

주소 뒤에 붙이면 그 상태로 시작합니다: `?흥분=40&만족=20&오일=50&배경=스파&코스=1` (영문 `a`, `s`, `oil`, `bg`, `course`도 됩니다). 마사지 중이나 결과 화면의 **상태 복사** 버튼은 흥분도·만족도·호감도·오일·많이 만진 곳·뭉침·약점·요청·절정/극락 횟수(결과 화면에선 평가 포함)를 텍스트로 복사합니다. 채팅에 그대로 붙여 넣으면 됩니다.

시작 버튼 또는 캐릭터 화면을 탭하면 움직임과 합성 BGM이 시작됩니다. 오른쪽 위에서 음악과 효과 설정을 조절하세요. 옷의 불투명한 부분을 누르거나 드래그하면 메쉬가 변형됩니다. 효과 설정의 디버그를 켜면 레이어를 개별 표시/숨김할 수 있습니다.

## 설정

`index.html` 상단의 한국어 `CONFIG`에서 효과 강도, 주기, 스프링, 감쇠와 음악 음량을 변경하세요. `눌림.가슴중심`은 topwear 경계 내 상대 좌표입니다. 다른 캐릭터를 사용하면 이 좌표를 조절하세요. 설정 패널의 변경은 해당 세션에만 적용됩니다.

PSD 순서를 유지하되 눈 레이어가 차지하던 슬롯만 흰자 → 홍채 → 속눈썹 순서로 교환합니다. 홍채는 흰자의 실제 alpha로 마스킹됩니다. 모든 레이어는 원본 PSD 좌표 기반의 메쉬이며, 그룹별 변형도 하나의 레이어 스택 안에서 처리합니다.

실제 Live2D 모델/리깅 파일이 아닌 PSD 레이어 기반 변형입니다. PSD에 없는 가려진 그림을 새로 만들지는 않으므로 고개 회전과 변형은 작게 설정되어 있습니다. BGM은 외부 음원 없이 Web Audio로 합성합니다.

참고 API: [ag-psd](https://github.com/Agamnentzar/ag-psd), [PixiJS SimplePlane](https://pixijs.download/v7.4.3/docs/PIXI.SimplePlane.html).

## 확인한 동작

헤드리스 Edge에서 1440×1000 데스크톱과 390×844 모바일 터치 환경을 확인했습니다. 20개 레이어, 눈 그리기 순서와 2개 alpha 마스크, 모든 메쉬 정점의 유효성, 레이어 표시 토글, 눌림·드래그·해제, 깜빡임 복귀, 음악 시작·끄기, PSD 재로딩과 터치 취소가 정상 동작했습니다. 모바일에서 페이지 가로 넘침은 없었고, 설정 패널은 실제 터치 스와이프로 스크롤되었습니다. 테스트에서 JavaScript 실행 오류는 발생하지 않았습니다. 실제 모바일 기기별 성능은 별도 확인이 필요합니다.

## 움직임 품질 개선

- 양쪽 홍채는 같은 PSD 픽셀 이동량을 공유합니다. 실제 alpha 윤곽을 샘플링해 새로 드러나는 흰자 면적이 2.5%를 넘지 않도록 이동량을 함께 줄입니다. 위쪽 이동은 별도 제한합니다.
- 사용자 요청으로 자동 깜빡임을 끄고 관련 설정 슬라이더를 제거했습니다. 시선 추적과 눈 alpha 마스크는 유지합니다.
- 16px 둥근 프레임과 실제 WebGL 마스크로 전체 캐릭터를 자릅니다. 원본 하단의 8px를 잘라 머리카락이 몸 아래로 삐져나오는 것을 가립니다.
- 고개는 감쇠 스프링으로 부드럽게 움직입니다. 머리의 회전 중심을 통일하고, 목 연결부를 보정하며, 머리카락 뿌리를 고정합니다. 정지하면 머리카락의 지연도 사라집니다.
- 짧게 누른 순간에 가슴 스프링에 직접 힘을 주므로 드래그 없이도 출렁입니다. 옷의 외곽과 목선, 하단은 고정합니다. `클릭탄성`, `가슴스프링`, `가슴감쇠`는 옷의 눌림과 별도로 조절할 수 있습니다.
- 허리 입력의 반응 강도는 0입니다. 눌림·드래그와 다른 부위에서 전달되는 변형도 옷 높이의 50~62% 구간에서 감쇠시켜, 그 아래 허리는 호흡 이외에 변형되지 않습니다. 자동 깜빡임이 15초 동안 발생하지 않고, 허리 누르기·드래그에서 추가 메쉬 변형과 출렁임 전달이 모두 0임을 확인했습니다.

개선 후 CDN을 직접 로드한 테스트에서 극단 시선 6방향 모두 흰자 노출 한도 이내였습니다. 기본 단일 클릭의 가슴 변위는 최대 약 11 PSD px이며 네 차례 방향을 바꾸며 감쇠했습니다. 모바일 연속 12회 탭도 변위 제한 22px 이내에서 안정적으로 복귀했고, 설정 패널의 실제 스와이프·슬라이더·초기화를 확인했습니다. 이는 테스트 환경의 수치이며 프레임 전체 렌더링 성능을 나타내지는 않습니다.

## 마사지 반응 시스템

- **부위**: 가슴(민감, 흥분도만), 어깨·팔(만족도), 허리(만족도, 변형 없음). 가슴은 만족도를 올리지 않습니다. 마우스를 올리면 부위 태그와 손 커서가 나옵니다.
- **터치감**: 누른 지점이 손에 달라붙어 움켜쥔 채로 끌립니다(`눌림.드래그` 0~1, 1이면 손과 똑같이). `최대끌림`보다 멀리 끌 때만 접촉점이 손을 따라 이동하고, `미끄러짐`을 올리면 문지르는 느낌이 강해집니다. 팔은 `부위.팔주무름` 비율만큼 살이 따라옵니다.
- **흥분도(0~100)**: 가슴을 누르면 초당 `흥분.누르기`, 문지르면 화면 1000px/초당 `흥분.문지르기`만큼 더 오릅니다. 이미 달아오른 상태에선 다른 부위도 `다른부위`만큼 올립니다. 100에서 절정(하트 폭발·플래시·떨림), 이후 `여운`까지 내려옵니다. 75% 근처부터 하트 눈이 나타납니다.
- **만족도(0~100)**: 흥분도보다 천천히 오릅니다(같은 손놀림 8초 기준 흥분도 약 50, 만족도 약 29). 어깨·팔·허리를 `만족.적정속도` 구간으로 주무르면 초당 `상승`만큼 오르고, 가만히 누르면(지압) 절반, `거칠기한계`보다 빠르면 내려가며 "아파요" 반응이 나옵니다. HUD의 손놀림 막대 초록 구간이 적정 속도입니다. 100에서 극락 연출(반짝이·민트 플래시·종소리) 후 `여운`까지 내려옵니다. 만족할수록 숨이 느려지고 눈이 나른하게 감기며 고개가 기웁니다.
- **적정 구간 변화**: 만족도가 오를수록 근육이 풀려 적정 속도 구간이 더 빠른(센) 쪽으로 옮겨가며 좁아지고, 흥분도가 오를수록 예민해져 느린(부드러운) 쪽으로 옮겨가며 좁아집니다. 손놀림 막대의 초록 구간이 실시간으로 움직입니다. 이동량과 폭은 `CONFIG.구간변화`에서 조절합니다(예: 만족 100·흥분 0이면 약 430~720px/초, 만족 0·흥분 100이면 약 45~290px/초).
- **몸 반응**: 가슴 터치 때 양팔 움찔(`반응.팔움찔`, `팔최대각`, `움찔빈도`)과 고개 젖힘. 흥분할수록 숨이 빠르고 입이 벌어지며 홍조가 짙어집니다(`홍조`, 위치는 `홍조선`).
- **대사창**: 이름표가 있는 대사창에 한 글자씩 나옵니다. 흥분도 단계(평온~절정)와 만족도 단계(뭉침~극락), 아픔 대사를 `CONFIG.대사`에서 고칠 수 있습니다.
- **소리**: 흥분도 30% 이상 심장 소리, 만족도 단계가 오를 때 종소리(`효과음.음량`).

## 배경

오른쪽 위 그림 버튼으로 배경을 고릅니다. 배경은 캐릭터 액자 안쪽 뒤에 깔리고, 이미지 배경일 때는 화면 바깥쪽에 흐린 같은 이미지가 깔립니다. 고른 배경은 브라우저에 기억됩니다. 이미지를 추가하려면 `assets/bg/`에 파일을 넣고 `CONFIG.배경.목록`에 `{ 이름: '마사지실', 이미지: './assets/bg/room.jpg' }`를 추가하세요. `내 이미지 불러오기`로 고른 파일은 그 창에서만 쓰이며 저장되지 않습니다.

## 게임 요소

- **도구**: 손과 오일. 오일 도구로 누르면 방울이 떨어지며 그 부위에 오일이 쌓입니다(가슴·허리·왼팔·오른팔 따로). 오일이 묻은 곳은 옷이 젖어 살색이 비치고(`오일.젖음`) 번들거리며(`오일.광택`), 더 잘 미끄러지고, 만족도·흥분도가 더 크게 오릅니다. 오일은 천천히 흡수됩니다.
- **숨은 뭉침·약점**: 세션마다 어깨·팔·허리에 뭉침 3곳, 가슴에 약점 1곳이 무작위로 숨겨집니다. 근처를 주무르면 고리가 희미하게 보이고 레이나가 힌트를 줍니다. 뭉침 안에서 `약점.풀기시간`초 주무르면 풀리며 만족도 +10, 약점을 찾으면 그 안에서 흥분도가 2.2배로 오릅니다.
- **요청**: 14~24초마다 레이나가 부위(어깨·팔, 허리, 흥분도 45 이상이면 가슴, 오일)를 요청합니다. 프레임 위쪽 배너의 제한시간 안에 들어주면 보너스, 놓치면 토라집니다.
- **익숙함**: 같은 부위만 계속 만지면 효과가 최대 60%까지 줄고 "다른 곳도…"라고 말합니다. 쉬면 회복됩니다.
- **두 손**: 모바일에서 두 손가락으로 두 곳을 동시에 주무를 수 있습니다(두 손 마사지는 각각 75% 효율).
- **코스와 결과**: 시작 화면의 "3분 코스"는 시간이 끝나면, 자유 모드는 **끝내기** 버튼을 누르면 결과 화면(S/A/B/C 평가, 점수, 통계)이 나옵니다. 평가에 따라 호감도가 쌓이고 이 브라우저에 저장됩니다. 호감도 Lv.3부터 첫인사가 바뀝니다.
- **반응 연출**: 손이 가슴 위에 오면 먼저 긴장해 움찔합니다(예감). 요청할 땐 플레이어를, 부끄러울 땐 다른 곳을 봅니다. 한 곳을 0.5초 이상 누르면 그쪽으로 확대되고, 절정·극락 땐 얼굴 쪽으로 확대됩니다. 한계 직전·절정·극락·약점 발견 때 프레임 오른쪽 위에 얼굴 클로즈업 컷인이 뜹니다. 흥분하면 숨을 내쉴 때 입김이, 흥분·이완이 높으면 땀방울이 맺힙니다.
- **소리·진동**: 손 속도에 맞춘 문지르는 소리(오일이면 젖은 소리), 오일 방울, 요청 알림, 흥분도에 따라 차오르는 BGM 패드와 빨라지는 템포. 모바일은 움찔·뭉침 풀림·절정·심장 박동에 진동합니다(설정에서 끌 수 있음).
- **설정 패널**: 자주 쓰는 항목만 먼저 보이고, 나머지는 "세부 조절 (개발자)"에 접혀 있습니다.

## itch.io 배포

itch.io는 게임을 별도 도메인의 iframe에서 실행하므로 PixiJS까지 zip 안에 넣은 배포본을 씁니다. 저장소 루트에서:

```bash
npm install --no-save pixi.js@7.4.3
node tools/build-itch.cjs
```

`dist/reina-massage-itch.zip`(약 1.2MB)이 만들어집니다. itch.io 프로젝트의 종류를 HTML로 하고 이 zip을 올린 뒤 "브라우저에서 플레이"를 체크하세요. 권장 화면 크기는 1280×800, 모바일 지원과 전체화면 버튼을 켜두면 됩니다. itch 페이지 주소에 붙인 `?흥분=40` 같은 링크 파라미터는 iframe 안까지 전달되지 않으니, 링크 시작 상태가 필요하면 GitHub Pages 주소를 쓰세요.
